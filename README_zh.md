# BlindGrid

**局部观察下的视觉证据获取与使用诊断**

Jiazheng Liu、Wanpeng Zhang、Zongqing Lu  
COLM 2026 Workshop on Efficient Reasoning · [论文记录](https://openreview.net/forum?id=MjJALedynI) · [English](README.md)

BlindGrid 让多模态大语言模型每次只能看到图片的一小块，由模型决定往哪里移动、保留哪些信息，以及什么时候回答。我们主要评价答案质量，也检查模型走过哪里、记录过什么，以及最后如何把看到的属性或关系对应到问题中的目标。

这个仓库提供论文的配套材料，帮助读者了解实验设置、查看具体案例，并在材料补齐后重新计算主要结果。

## 当前已提供

- [目录说明](docs/STRUCTURE.md)：各类材料的位置和用途。
- [方法说明](docs/protocol.md)：模型如何观察、移动、保留历史，以及步数限制。
- [10 份完整初始提示词导出](docs/prompts/README.md)：五种设置，各包含两种网格版本。
- [文件校验清单](release_manifest.json)：记录本批文件的大小与 SHA-256 摘要，便于核对下载内容。

提示词来自保存的代码版本，按原始字节保留。它们说明初始指令的内容，完整运行还涉及问题、后续消息和历史构造。具体来源与使用说明见[提示词索引](docs/prompts/README.md)。

## 后续逐步补齐

| 材料 | 用途 |
|---|---|
| 题目、参考答案和最终评分规则 | 了解问了什么、如何判断答案 |
| 保存的评分和探索轨迹 | 查看观察过程与最终回答 |
| 离线复核包 | 用保存的数据重新计算主要统计结果 |
| 补充分析与图源 | 核对敏感性分析、图表和案例来源 |
| 图片来源与裁剪信息 | 定位具体图片版本，了解图块怎样生成 |
| 最终论文 PDF 与引用文件 | 将论文版本与材料版本对应起来 |

主评估包含两幅作品上的十道题、共 1500 次尝试。视觉控制包含 360 个回合，补充图片评估包含五幅图片上的 16 道题、共 64 个回合。这些是论文的评估范围，当前仓库先提供上面列明的说明与提示词。

建议先读方法说明，再比较提示词。现有离线包将整体接入 `reproducibility/`，并在验证后提供运行命令。离线核对使用保存的模型输出，无需调用模型 API。

本批为文字材料。图片提供方式、精确来源和相关使用条款将单独说明。仓库许可条款待补充。
